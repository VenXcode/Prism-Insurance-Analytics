# Dataset

This folder contains the Excel datasets used in the Prism Insurance Analytics project.

## Files

| File                               | Description                                                               |
|------------------------------------|---------------------------------------------------------------------------|
| `Insurance-Customer-Feedback.xlsx` | Input customer feedback data used for sentiment analysis                  |
| `Insurance_Sentiment_Results.xlsx` | Processed output containing sentiment classifications and compound scores |

## Usage

The customer feedback dataset is processed using the Python sentiment analysis script in the `Python-Automation` folder.

The generated sentiment results can be connected to Power BI for customer feedback analysis.
